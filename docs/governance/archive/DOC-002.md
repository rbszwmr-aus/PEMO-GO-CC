## What to build

Not code — a **reuse map** of the existing `origin/main` against the rewrite's KEEP/REWRITE decisions, so the migration PIDs migrate sound code rather than re-type it. **Unit of audit = the package/module; evidence = a path.**

Classify every package/module into exactly one, with evidence:

| Verdict | Meaning |
|---|---|
| **KEEP-AS-IS** | Cleanly implements a KEEP decision, tests green at the pin, not coupled to churn. |
| **REFACTOR** | Sound in substance but carries amendment scars or is coupled to a decision being re-sequenced (identity / role / party). |
| **REBUILD** | Implements a decision that has since changed, or was a wrong-first-attempt. |
| **DROP** | Dead or superseded. |

Verdict against **in-repo `docs/adr/` at the pin**, labelled as such (the rewrite keeps the architecture, so the repo's own ADRs are the current oracle; REBUILD-by-decision-change is expected near-empty). Cover the contract packages + governance tooling, the scope/authorization model, Property Core + seed machinery, the four module-boundary layers, `resident-mobile`, `resident-portal`, `management-web` front end + backend, and the classification pipeline. Name anything outside this list.

## Done when

- Every package/module is in the table with a verdict **and** a path-level evidence line — audit count == tree count, no silent omission.
- Each KEEP-AS-IS is backed by that module's tests green at the pin — the command and its result, not asserted.
- Anything that looks reusable but fails a boundary check is flagged even if its tests pass.
