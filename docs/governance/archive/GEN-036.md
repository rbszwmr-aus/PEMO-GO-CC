# GEN-036 — R5b: code hygiene, by derivation

**A rule whose membership is grepped by hand is a suggestion.**

`R5` moved six governance conventions from memory into enforcement. `R5b` does the
same for five code-level ones, and each takes the `ADR-018` instinct — derive the
membership from a source of truth, or make the wrong thing unrepresentable —
rather than sweeping once and hoping.

- **H1** `LIKE` escaping. `likePattern`/`likePrefix` build a pattern that matches
  its input literally; `like-escape.sh` requires every `LIKE` in the tree to
  account for its wildcards, so a new call site is covered when it is written.
- **H2** fixture idempotency. `fixtures-idempotent.sh` derives the PROPERTY and
  names the mechanism — `ON CONFLICT`, `DELETE`-first, or a temp table.
- **H3** the refusing-command set. `RefusalKind` is the union of the commands'
  own refusal types, and the compiler holds the runtime array to it.
- **H4** `with-mutation.sh`. Mutation testing that cannot destroy uncommitted work.
- **H5** validator codes. A declaration the consumer reads, replacing a grep of
  the call sites that resolved 73 codes out of 120 calls.

No contract change and no migration: this PID is tooling and internals.
