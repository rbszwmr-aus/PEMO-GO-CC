## Close note — THE BOOTSTRAP IS NOT SELF-CONTAINED

**A genuinely empty organization still cannot be provisioned.** The provisioning act confers the first
grant on a GROUP, and the group must already exist — creating one is the group-administration surface
(`W3`) and was not built here. So the act works, and is proven, only where a group has been put in
place by other means.

**`W2` alone does not remove the DBA. `W2` + `W3` does.**
