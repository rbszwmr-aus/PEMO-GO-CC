# GEN-026 — W1d: the authority-bearing source becomes `principal`

`GEN-025`'s check found that `staff` **under-names** the value. The schema already declares
`'resident'` in `audit_event_role_check` and in `scope_grant`'s role CHECK, so the model anticipates
a resident actor — and under `0119`'s origin-not-channel rule a resident's own act **is** that
person's act carrying their own authority, the same category as a staff act. The enum is not
incomplete; the name is too narrow.

`principal` is ADR-010 D1's own word, and the biconditional then reads almost tautologically:
**authority is present iff `source = 'principal'`**.

**Now, because zero audit rows exist.** This is a pure rename today and a data migration the moment
a row exists. It also lands before `W2`, which would otherwise build against a name about to change.
