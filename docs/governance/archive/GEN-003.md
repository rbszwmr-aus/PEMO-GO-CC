**Step 1 established that the tool is broken three ways and that its Step-1 zero is an empty oracle.** v1.1 fixes the three, then earns the answer:

1. **The config cannot resolve.** `options.tsConfig.fileName` is repo-root-relative while the `extends` chain is resolved relative to the config's own directory, and no working directory satisfies both. Resolution proposed and proven at Step 1.
2. **`no-module-to-module` has never worked.** It captures `^modules/([^/]+)/` and never back-references the group, so it forbids a module importing its own files — 32 violations, all intra-module, none genuine. Needs `pathNot: '^modules/$1/'`.
3. **`npx <bare-name>` is banned.** The v1.0 text told the executor to run `npx depcruise`, which fetched a dependency-confusion placeholder from the public registry and exited 0. Invoke local devDependencies by explicit binary path. Scrub the string wherever `DOC-002` wrote it, and add a grep-guard so it cannot re-enter by copy.
