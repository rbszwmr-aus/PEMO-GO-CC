# GEN-060 — the genesis route is off the public surface (readout R1)

The seed/demo/production readout found the first-administrator bootstrap is a real, operator-reachable
act — `provision()` — but reachable over the CUSTOMER-FACING HTTP surface at
`POST /api/management-web/v0/organizations/:organizationId/provision`, registered unconditionally, the
ONLY route not behind `authenticateStaff`, guarded solely by zero-grants-ever.

**The invariant is right — the first administrator cannot require an administrator. The EXPOSURE is
not:** between an organization row existing and its provisioning, anyone who can reach the surface and
knows or guesses the org id becomes its administrator, permanently — and the invariant then works FOR
the attacker, because the real customer can never provision. "Network/ingress controls this codebase
does not enforce" is a hope, not a control.

## Requirements (ruled; implementation is Main CC's)

- (a) The genesis must NOT be reachable from the public management surface.
- (b) It must be reachable by an OPERATOR ON THE HOST — the dev-token CLI is the shape: an act invoked
  where the server runs, not over the customer-facing HTTP surface.
- (c) If an HTTP path must remain, it requires a one-time provisioning secret issued when the
  organization row is created, and the route is refused without it.
- (d) The zero-grants-ever invariant STAYS as the inner guard — correct, and nothing replaces it.
- (e) Bites: the public route no longer provisions; the operator path does; a second attempt is still
  refused by the invariant.

## Chosen shape

**(a) + (b) + (d): remove the public HTTP genesis route; genesis becomes an operator CLI run on the
host, calling the same `provision()` act; zero-grants-ever stays the inner guard.** Chosen over (c)
because genesis is an operator action, not customer self-serve — a property-management system's first
administrator is created by whoever deploys it, on the host, with the database credentials, exactly as
`dev-token` is. Removing the surface eliminates the exposure rather than papering it with a secret.

Report states the exposure and for how long it existed; management-web's `provisionOrganization`
act-vocabulary entry is flagged for UI CC (no genesis UI exists; it is a generated enum member).
